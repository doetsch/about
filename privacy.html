Privacy Policy — Hermes Personal Sync

Last updated: 30 October 2026

This application is a personal tool operated by Patrick Doetsch ("the operator") for their own Google account. It is not offered, marketed or made available to anyone else, and it has no other users, customers or accounts.

What the application accesses

The application requests the narrowest Google scopes that its two functions need:

  • Google Health (read-only): activity and fitness data, health measurements (weight, body composition, heart rate, resting heart rate, SpO2, HRV, ECG, blood glucose), sleep, nutrition and hydration records.
  • Gmail (read-only) and Contacts (read-only) — used only to summarise the operator's own inbox and address book for them.
  • Calendar, Drive, Docs and Sheets — read and write, so the tool can create the operator's own reports, notes and calendar entries.

No other Google data is requested, and the operator can view or shrink the granted scope list at any time at myaccount.google.com/permissions.

Where the data goes

  • Data is requested directly from Google over HTTPS by computers the operator owns and physically controls, in their home.
  • It is processed and stored only on that hardware, on the operator's private local network.
  • It is not transferred to, sold to, rented to, or shared with any third party, and it is not used for advertising, profiling, research or analytics.
  • The application contains no tracking code, no analytics, and no third-party servers. It makes network requests only to Google's own APIs.
  • The operator's dashboard and reports are served only inside their home network and are not reachable from the internet.

Retention and deletion

Health and account data cached by the application is stored in files and databases on the operator's own machines. The operator may delete any or all of it at any time, and does routinely. There is no backup or copy held by anyone else.

Revoking access

The operator can revoke this application's access immediately and permanently at myaccount.google.com/permissions. Revoking stops all data access at once; no further data is then retrievable.

Security

OAuth credentials are stored on the operator's own machines with owner-only file permissions, never in source code repositories, and never transmitted anywhere except to Google's token endpoint. Access to the machines is limited to the operator.

Changes

If the application's data use ever changes, this page is updated and its date amended before the change takes effect.
